# SplineFlow-Panda v0.3.0

This release provides a measured MuJoCo comparison between discrete action chunks
and continuous cubic B-spline actions, paired task seeds, report validation, a guided
Streamlit dashboard, and an experimental matched state-policy pipeline.

The included two-seed benchmark is a development result. The scripted ten-seed,
three-scenario milestone command is provided for final local reproduction. Learned
closed-loop results are not promoted unless both representations satisfy the documented
80% success gate on ten unseen layouts.
